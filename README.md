# SolidWorks CAD Portfolio

A collection of mechanical design projects built in SolidWorks, spanning machine design, sheet metal design, and mechanism design. Each project folder includes native SolidWorks files, STEP exports (for viewing without SolidWorks), PDF drawings with GD&T callouts, and renders.

## Skills Demonstrated

- Complex assembly modeling and mating (multi-part, high part-count assemblies)
- Sheet metal design: flanges, bend flanges, forming tools, flat pattern development
- GD&T and manufacturing drawing sets
- Mechanism design and motion (cam profiles, four-bar linkages)
- Standard fastener modeling and assembly (nut-bolt, threaded connections)

## Repository Structure

```
/project-folder/
  ├── native-files/      # .SLDPRT / .SLDASM (SolidWorks required to open)
  ├── step/               # .STEP exports (viewable in any CAD viewer or browser)
  ├── drawings/           # PDF drawings with dimensions, tolerances, GD&T
  └── renders/            # Screenshots / rendered images / motion study clips
```

## Notes

Native SolidWorks files are included for completeness but are binary and not meaningfully version-controlled by Git. STEP files and PDF drawings are the recommended way to review each design without SolidWorks installed.
